## 先分清：是平台出问题，还是只有你不行

判断方法很简单：换设备、换网络、问别人。这三件事做完，问题的范围基本就锁定了。

具体这样操作：

1. 在同一网络下打开别的网站或App，确认不是整个网络都断了
2. TikTok在Wi-Fi和移动数据之间切换着试，看是不是只有其中一种网络不行
3. 用网页版，或者借一台别的设备登录同一个账号试试
4. 问一下身边同地区的朋友能不能正常刷

也可以顺手查一下公开的状态监测网站。至少到2026年8月上旬，几家监测服务的数据都显示TikTok美国区运行正常，只有零星的个案报告。换句话说，你遇到的“不稳定”大概率是个别环节的问题，平台大规模故障的可能性很低。

不同现象对应的常见原因差很多，先对号入座再动手：

| 你看到的现象 | 更可能的原因 |
| --- | --- |
| 整个App打不开，其他网站正常 | 本地网络、App版本过旧、缓存损坏 |
| 视频能刷，评论、收件箱、收藏打不开 | 单一功能故障或账号限制 |
| 闪退、黑屏 | App或系统版本问题、缓存损坏 |
| 登录不上 | 密码、验证出问题，或账号被限制 |
| 某个功能直接消失 | 年龄要求、地区可用性或灰度发布 |
| 换一条Wi-Fi就正常了 | 原网络的问题：路由器、DNS，或该网络屏蔽了TikTok |

最后一种情况值得单独提一句：公司、学校和公共场所的网络屏蔽TikTok并不少见。办公环境Wi-Fi下刷不动，切到流量立刻就通，这种例子很常见。

## 官方排查就这6步，按顺序做

TikTok官方给的排查顺序是：更新App → 更新系统 → 换网络 → 重启 → 清缓存 → 网页版验证。每做一步就测一次，哪一步解决了，原因也就顺带找到了。

1. 更新TikTok：去App Store或Google Play装上最新版本
2. 更新手机系统：尤其是闪退、黑屏的情况，旧版系统经常就是直接原因
3. 换网络：Wi-Fi切流量，或换一个Wi-Fi环境，这一步能立刻判断问题是否出在你的网络上
4. 彻底重启App和手机：从后台把TikTok完全划掉再重新打开，切出去再切回来不算
5. 清缓存：TikTok内依次打开 Profile → 菜单 ☰ → Settings and privacy → Free up space，清除缓存；安卓也可以走系统设置 → 应用 → TikTok → 存储 → 清除缓存
6. 网页版验证：浏览器直接打开TikTok。网页能刷而App不能刷，问题在App本身；网页也刷不动，再往线路层面查

排查期间有一件事别做：反复卸载重装。卸载会连带删掉还没保存的草稿，而如果是服务器端或账号侧的问题，重装一百次也不会有任何改善。

还有一类容易误判的情况：视频加载完全正常，但发不了作品、评不了论、私信用不了。这大概率已经和网络无关。TikTok自带账号检查工具，路径是 Profile → 菜单 ☰ → TikTok Studio → More tools → Account check（另一条路是 Settings and privacy → Support → Safety Center → Account check），能直接看到登录、发布、评论、私信有没有被限制。不少人把限流当网络问题折腾半天，先花两分钟跑一遍这个检查再说。
